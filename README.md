## LEARNED WHAT IS AZURE?
** AZURE IS A CLOUD COMPUTING PLATFORM/PROJECT RED DOG 
** ITS LIKE A DIGITAL STOR FOR RENTING THE SERVICES LIKE( STORAGE AND MEMOREY AND DATABASES_) ETC
** BASED ON 3 CLOUD MODELS 
# IAAS (INFRASTRUCTURE AS A SERVICE) most responsibilty on the consumer for physical security , power and connectivity.
# SAAS (SOFTWARE AS A SERVICE) most responsibilty on the cloud provider 
# PAAS (PLATFROM AS A SERVICE) acts as a bridge/middle grounf btw the cloud provider and consumer (BTW IAAS AND SAAS)
** IT HAS 3 CLOUD DEPLOYMENT MODELS 
# PUBLIC CLOUD ( GENERAL PUBLIC ACCESS ) 
# PRIVATE CLOUD ( SINGLE ORGANIZATION AND MAINLY FOR AUTHORIZATION AND AUTHENTICITY )
# HYBRID CLOUD ( PUBLIC + PRIVATE )
# MULTI CLOUD ( TWO OR MORE PROVIDERS )
** TERM IT MARKETING BUDGETING
# capEX ( CAPITAL EXPENDITURE ) upfront spending like for servers , hardare and network etc
# opEX ( OPERATIONAL EXPENDITURE ) on going spending
